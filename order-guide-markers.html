Order guide · Markers

Seven icons, three tiers, one tooltip

This page shows how every marker on an order guide line looks, where it sits, and what a tap opens. The same system works for every store. Store flags switch off the parts a store does not have. Section 7 lists what changes against the app as it is built today.

2In the order guide

Tap any icon. Switch the store type to see what a store without a preorder column and without order guide changes during the day gets.

3Placement and stacking

Cell icons

  • 8 px right of the cell they belong to.
  • At most two per cell, stacked vertically 4 px apart and centred on the cell.
  • Order from top, as built today: the field's own ! / ? or lock, then recalculated, then edited, then info. A locked field never shows ! or ?.
  • An icon only exists where its column exists. No preorder column means no preorder icons.
  • Column order as in the app: Item, Inventory, Order, Preorder.

Line icon

  • The order guide icon sits directly behind the item name, centred on its first line, also when the name wraps.
  • It also shows on lines the user edited and on locked lines: a case size change changes the volume behind the user's number.
  • A removed line is greyed and locked. It shows only the order guide icon, never ! or ?, because the user cannot act on it.

  • The tooltip opens under the icon and points at it. One tooltip open at a time.
  • It closes on a tap outside, on scroll, and when the list re-renders. The icon is rebuilt on every render, so the tooltip must not outlive it.
  • It is not a bottom sheet. Reading why a line is flagged is not a task, and users tap several icons in a row while walking the shelf.
  • All texts in DE / EN / FR, reviewed by design before release.
  • No count needed shows only where no count changes the order, and names the case: "Whatever you count, the order stays at N CS", or for items without a forecast "No forecast for this item yet. Enter the quantity you want to order." together with the order quantity warning. Locked lines never say it.

5When the order guide changes during the day

Only for logos that receive several order guide files per order day. One item over one order day:

10:00 file
Item arrives
No marker
12:00 file
Sales price changes
Sales price changed
15:00 file
Case size and price change
Case size changed, Sales price changed
User edits the order
Marker clears
No marker until the next change

Rules

  • The backend sends the changed fields with the existing flag: sales price, promo start, promo end, case quantity, case unit, added.
  • Lines in this order, each once: Case size changed (quantity or unit), Promo dates changed (start or end), Sales price changed.
  • Changes collect from the moment the marker appears.
  • The marker stays until the user edits the order quantity on that line after the change, or a new order day starts.
  • The recalculated icon no longer lights up for order guide changes.
  • Filter and sort: "Order guide changed" next to "Recalculated", only when the toggle is on.

Added and removed items

  • Added: in a later file of the day but not in an earlier one. Tooltip: "Added to today's order guide". This is deliberately not "New item", which stays the reason for an item that is new to the store.
  • Removed (separate module, ships later): in an earlier file of the same day and missing from a later one, or case content quantity 0. The line stays, greyed and locked, all its quantities forced to 0, moved to the bottom (to be confirmed). Tooltip: "Removed from order guide".
  • Items that dropped out between days are not marked.
  • A removed item that comes back the same day becomes active again as "Added to today's order guide".
